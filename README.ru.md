# Beautiful

**Beautiful** — открытая (open source) программа для цифрового рисования.

> **Альфа** — нестабильная версия. Ожидайте баги и недоделанные инструменты. Выложена на GitHub для **бета-тестеров**, которые хотят попробовать ранние сборки и дать обратную связь.

В будущем планируется **бета**-версия.

## Статус

| | |
|---|---|
| Стадия | **Альфа** |
| Стабильность | Нестабильно — баги ожидаемы |
| Прогресс инструментов | Около **~7%** от запланированного набора |
| Лицензия | [MIT](LICENSE) |
| Для кого | Ранние / бета-тестеры |

## Что это

- Программа для **рисования**
- **Полная кастомизация интерфейса** — можно гибко настраивать UI под себя
- Поддержка **аддонов**
- **Open source** (MIT)

## Что планируется дальше

- Переделка и доработка системы **кистей**
- Дальнейшая **оптимизация** производительности
- Расширение набора инструментов
- Переход от альфы к **бета**-версии

## Стек

| Слой | Технология |
|------|------------|
| Язык | Rust 2021 |
| UI | egui + eframe |
| GPU | wgpu (через eframe) |
| Перо | Windows Ink / сила указателя egui (WinTab в планах) |

## Требования

- [Rust toolchain](https://rustup.rs/) (stable)
- Windows 10/11 (основная платформа)
- XP-Pen / Wacom / любой планшет с Windows Ink или WinTab

## Запуск

```bash
cargo run -p beautiful-app
```

Release-сборка (быстрее обновления холста):

```bash
cargo run -p beautiful-app --release
```

## Управление

| Действие | Клавиша |
|----------|---------|
| Кисть | `B` |
| Ластик | `E` |
| Новый слой | `Ctrl+L` |

Рисуйте пером или мышью (ЛКМ). Давление отображается в строке статуса.
