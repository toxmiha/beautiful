# Beautiful

**Beautiful** — открытая (open source) программа для цифрового рисования.

> **Альфа** — нестабильная версия. Ожидайте баги и недоделанные инструменты. Выложена на GitHub для **бета-тестеров**.

В будущем планируется **бета**-версия.

## Скачать

Свежая Windows-сборка — в **[Releases](https://github.com/toxmiha/beautiful/releases)**  
(например `Beautiful-0.4.7.exe`). К каждому релизу GitHub также прикладывает исходники (Source code), как обычно.

## Что это

- Программа для **рисования**
- **Полная кастомизация интерфейса**
- Поддержка **аддонов**
- **Open source** (MIT)

## Что планируется дальше

- Переделка и доработка системы **кистей**
- Дальнейшая **оптимизация**
- Расширение набора инструментов
- Переход от альфы к **бета**-версии

## Требования (сборка Windows)

- Windows 10/11 (64-bit)
- GPU с DirectX 12 / Vulkan
- XP-Pen / Wacom / любой планшет с Windows Ink или WinTab (необязательно; мышь тоже работает)

## Сборка из исходников

```bash
cargo run -p beautiful-app --release
```

Нужен [Rust](https://rustup.rs/) (stable).

| Слой | Технология |
|------|------------|
| Язык | Rust 2021 |
| UI | egui + eframe |
| GPU | wgpu |
