# Beautiful

**Beautiful** — открытая (open source, [GPL-3.0](LICENSE)) программа для цифрового рисования.

> **Альфа** — нестабильная версия. Ожидайте баги и недоделанные инструменты. Выложена на GitHub для **бета-тестеров**.

В будущем планируется **бета**-версия.

## Скачать

Свежие сборки — в **[Releases](https://github.com/toxmiha/beautiful/releases)**  
Windows: распакуй `Beautiful-0.4.9-windows-x64.zip` и запускай `Beautiful.exe` **из этой папки** (рядом должны лежать DLL CPython — один `.exe` без них не стартует). Linux x64 — когда приложен к релизу. К каждому релизу GitHub также прикладывает исходники (Source code).

## Что это

- Программа для **рисования**
- **Полная кастомизация интерфейса**
- Поддержка **аддонов**
- **Open source** ([GPL-3.0](LICENSE))

## Что нового в 0.4.9

- Текст на холсте (живой layout + растеризация)
- Python-аддоны со встроенным CPython (Windows) + Music Player
- Геймпад / Steam Deck, язык интерфейса (i18n)
- Библиотека пресетов, ABR и папки кистевых ассетов
- Display-tile present (вместо старого полного mip)
- Export Studio, запись/повтор демо
- PSD / файлы, фильтры, live transform и многослойная композита

## Что нового в 0.4.8

- Движок кисти v2 (opacity/flow, spacing, scatter, dynamics, dual brush, вход в node editor)
- Редактируемые кривые давления планшета + эмуляция давления мышью
- Filter Studio (стек фильтров с живым превью, затем Apply)
- Discord Rich Presence (статус сессии; NSFW скрывает имя холста и превью)
- Splash при запуске, опциональная проверка обновлений с GitHub Releases
- Оптимизации paint-path и многослойной композиты

## Что планируется дальше

- Дальнейшая работа над кистями и производительностью
- Расширение набора инструментов
- Переход от альфы к **бета**-версии

## Требования

**Windows**

- Windows 10/11 (64-bit)
- GPU с DirectX 12 / Vulkan
- Планшет необязателен (Windows Ink / WinTab); мышь тоже работает

**Linux**

- x86_64, Vulkan (Mesa; сборки под Steam Deck / SteamOS — когда есть в релизе)

## Сборка из исходников

```bash
cargo run -p beautiful-app --release
```

Нужен [Rust](https://rustup.rs/) (stable).

| Слой | Технология |
|------|------------|
| Язык | Rust 2021 |
| UI | egui + eframe |
| GPU | wgpu |
